# Accessibility

- Never communicate status by color alone.
- Pair status colors with text such as PASS, WARN, FAIL, or READY.
- Maintain readable contrast on dark surfaces.
- Keep minimum interactive height near 24 pixels for WoW 3.3.5a.
- Provide tooltips for compact controls.
- Destructive actions require explicit language and confirmation.
- Reports must remain understandable when copied as plain text.
