# Colors

| Token | Hex | Meaning |
|---|---:|---|
| Inspect | `#1F6FB2` | Search, facts, information |
| Diagnose | `#D4A017` | Analysis, attention, uncertainty |
| Resolve | `#4CAF50` | Corrective action and success |
| Operate | `#B6C0CC` | Maintenance, verification, systems |
| Background | `#0E1218` | Application background |
| Surface | `#171C22` | Panels and cards |
| Border | `#596673` | Separation and focus |
| Text | `#ECEFF4` | Primary text |
| Muted | `#9AA5B1` | Secondary text |
| Danger | `#E34540` | Destructive or failed states |

Workflow colors must not be used as decoration alone. They communicate meaning.
