# Typography

WoW 3.3.5a uses client-provided font objects for compatibility.

Hierarchy:

- Window title: `GameFontNormalLarge`
- Workspace title: `GameFontNormalLarge`
- Section title: `GameFontNormalSmall`
- Body: `GameFontHighlightSmall`
- Dense table content: `ChatFontNormal`

Use sentence case for user-facing labels. Use uppercase only for compact workflow
or section markers.
